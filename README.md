    A persistent draggable live clock to manage and track your Office Hours.
  <br />
  </h2>
</div>

<p>Mostly in an Organization we spent our 8 hours. what if we can manage our task by tracking our time. TaskXL helps you to track your timings at office. with TaskXl you can check-In, see how much time left to leave, how much buffer time you stored, also you can perform check-out. It's minimalist dashboard navigates you to see your day-wise time spent and how much progress in time you made.
It also has a Live Clock. with future scope of different version of this extension. Currently, It is in Beta (v1.0) version.</p>

## Features

- ⏱️ Live Clock
- 🫷 Check-In/Check-Out Functionality
- 🫙 Calculates Buffer Time
- 📶 Dynamic progress bar based on time spent
- 📊 Simple Ui
- 🧹 Flush Buffer Feature

## How to use it in Chrome ?

- Download the project in .zip version 
- extract the TaskXL.zip
- you will get TaskXL Folder
- open chrome extension manager (chrome://extensions)
- click on Load Unpacked
- upload the TaskXL Folder

 You can see the TaskXL Icon, in the extensions section
